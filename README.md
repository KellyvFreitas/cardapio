# 🍔 Cardápio Digital — BurguerHub

Projeto de portfólio: um cardápio digital de hamburgueria construído com Nuxt 4, Vue 3 e Tailwind CSS v4. Interface responsiva com busca, filtro por categoria, carrinho de pedidos e modo escuro.

## Screenshot

![Print do cardápio digital](public/assets/image.png)

## Funcionalidades

- 🍽️ Catálogo de itens organizados por categoria (Lanches, Combos, Bebidas, Sobremesas)
- 🔎 Busca por nome/descrição e filtro por categoria
- 🛒 Carrinho de pedidos com ajuste de quantidade e total
- 🪟 Modal de detalhe do item
- 🌗 Alternância entre tema claro e escuro (com persistência local)

## Tecnologias

- [Nuxt 4](https://nuxt.com/)
- [Vue 3](https://vuejs.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Quasar](https://quasar.dev/)

## Como rodar

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento em `http://localhost:3000`:

```bash
npm run dev
```

Build de produção:

```bash
npm run build
npm run preview
```

## Observação

Este é um projeto de portfólio com dados fictícios (mock) — não há backend nem processamento real de pedidos.
